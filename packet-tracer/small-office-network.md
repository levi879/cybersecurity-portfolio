Cisco Packet Tracer: Small Office Network

Project Status

Planned

Objective

Design and simulate a small office network using Cisco Packet Tracer to practise networking fundamentals and troubleshooting.

Skills Practised

- Network topology design
- IPv4 addressing and subnetting
- Router and switch configuration
- DHCP and DNS fundamentals
- Connectivity testing using ping
- Network troubleshooting

Planned Network Design

The network will include:

- One router
- One switch
- Multiple office PCs
- An IPv4 address range: "192.168.10.0/24"
- Default gateway: "192.168.10.1"
- DHCP for automatic IP address assignment

Testing Plan

1. Verify that devices receive valid IP addresses.
2. Check the default gateway configuration.
3. Test connectivity between PCs using ping.
4. Investigate and document any connectivity problems.

Results

To be completed after building and testing the network in Cisco Packet Tracer.

Evidence
